## Завдання 5: Захоплення змінних (Capturing)

### Фактичний вивід:
1. `Змінна після лямбди: False`
2. `Цикл for: 3 3 3`
3. `Цикл foreach: 0 1 2`

### Пояснення:
1. **Змінна після лямбди:** Захоплюється посилання на змінну `threshold`, а не її значення на момент створення лямбди. Зміна значення на `1000` вплинула на виконання лямбди.
2. **Лічильник циклу for:** Змінна `i` оголошується один раз для всього циклу. Усі лямбди захопили посилання на одну змінну `i`, яка після завершення циклу дорівнює `3`.
3. **Те саме з foreach:** У C# змінна ітерації `foreach` створюється заново на кожній ітерації, тому кожна лямбда захоплює власну змінну.

**Як виправити пункт 2:** Створити локальну копію всередині циклу: `int copy = i; funcsFor.Add(() => copy);`.

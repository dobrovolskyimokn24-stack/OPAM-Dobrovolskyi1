# Лабораторна робота №3 — Рекурсивні алгоритми

## Параметри варіанта
* **N:** 7
* **K:** 17
* **a:** 1 (Кількість елементів, більших за 7)
* **b:** 3 (Файли .cs та їхній розмір)
* **c:** 2 (Підйом на 6 сходинок)

## Базові випадки
* **Завдання 1:** Каталог без підкаталогів (цикл обходу порожній).
* **Завдання 2:** Масив з одного елемента (lo == hi).
* **Завдання 3:** Залишок сходинок дорівнює 0 (remainingSteps == 0).

## Завдання 4 · Вивід трасування

enter Count(0..3)
  enter Count(0..1)
    enter Count(0..0)
      base Count(0..0) -> 0
    enter Count(1..1)
      base Count(1..1) -> 1
  exit  Count(0..1) -> 1
  enter Count(2..3)
    enter Count(2..2)
      base Count(2..2) -> 0
    enter Count(3..3)
      base Count(3..3) -> 1
  exit  Count(2..3) -> 1
exit  Count(0..3) -> 2

Рядки exit з'являються у зворотному порядку відносно enter, тому що стек викликів працює за принципом LIFO. Глибокий виклик має повністю завершитися та повернути значення першим.

## Завдання 5 · Відповіді

1. Для одновимірного масиву циклічний запис зрозуміліший і не створює накладних витрат на стек викликів O(log N).
2. Обхід папок має довільну глибину. Для циклу бракує допоміжної структури даних (Stack або Queue) для збереження незавершених шляхів.

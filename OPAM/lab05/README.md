## Завдання 5 · Обґрунтування вибору структур даних

1. **Завдання 1 (Дужки):**
   * **Чому стек:** Задача вимагає парності за принципом LIFO (останньою відкрилася — першою має закритися).
   * **Що зламалося б:** У разі використання черги (FIFO) закривальна дужка порівнювалася б із найпершою відкривальною, що повністю порушує правила вкладеності виразів.

2. **Завдання 2 (RPN):**
   * **Чому стек:** У зворотному польському записі оператор виконується над останніми зчитаними операндами.
   * **Що зламалося б:** У разі використання черги операція застосовувалася б до найперших введених чисел, змінюючи порядок обчислень і пріоритет операцій.

3. **Завдання 3 (Черга):**
   * **Чому черга:** Заявки обслуговуються у порядку надходження (FIFO) для забезпечення справедливості черги.
   * **Що зламалося б:** Якби взяли стек, найперші заявки чекали б нескінченно довго, обслуговуючись останніми (голодування процесів).

4. **Порівняння Queue.Dequeue() та List.RemoveAt(0):**
   Queue.Dequeue() виконується за O(1), оскільки черга реалізована як кільцевий буфер (змінюється лише вказівник на початок). List.RemoveAt(0) вимагає O(N) часу, бо всі N-1 елементів масиву зміщуються вліво на одну позицію в пам'яті.

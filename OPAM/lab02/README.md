# Лабораторна робота №2 — Алгоритми обробки масивів

## Параметри варіанта
* **N:** 7
* **K:** 17
* **a:** 1 (Фільтрація: Елементи, що кратні 3)
* **b:** 3 (Масив: 18 випадкових чисел у діапазоні [-3; 3], Матриця: 6x3)
* **c:** 2 (Перестановка: Циклічно зсунути вправо на одну позицію)

## Методи програми
* `Task1_Aggregate` — обчислення суми, середнього, мін/макс з індексами та кількості нулів за один прохід.
* `Task2_FilterMultiplesOfThree` — створення нового масиву точного розміру з елементами, кратними 3.
* `Task3_LongestSeries` — пошук найдовшої серії однакових елементів поспіль.
* `Task4_ShiftRight` — циклічний зсув масиву вправо на 1 позицію без використання додаткового масиву.
* `Task5_ProcessMatrix` — обробка матриці 6x3 (суми рядків, максимуми стовпців, рядок із найбільшою сумою).

## Завдання 3 · Крайові випадки

| Вхідні дані | Що очікуємо | Що вивела програма |
|---|---|---|
| Порожній вхід (одразу 0) | Сума: 0, Нулів: 1, Добуток: Немає даних | Сума: 0, Нулів: 1, Добуток: Немає даних |
| Рівно одне число (наприклад, 17, а потім 0) | Сума: 17, Нулів: 1, Добуток: 17 | Сума: 17, Нулів: 1, Добуток: 17 |

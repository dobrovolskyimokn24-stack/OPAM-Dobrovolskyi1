# Лабораторна робота №4 — Алгоритми над списками

## Параметри варіанта
* **N:** 7
* **K:** 17
* **a:** 1 (Залишаємо елементи, кратні 3)
* **b:** 3 (Розділяємо на парні та непарні індекси)
* **c:** 2 (Вилучаємо від'ємні елементи)

## Завдання 2 · Аналіз хибного вилучення
Під час видалення елемента за індексом $i$, усі наступні елементи зсуваються вліво. При кроці $i++$ цикл пропускає елемент, який перемістився на місце видаленого. Через це пропущено від'ємні елементи, які йшли підряд.

## Завдання 5 · Замір часу та аналіз швидкодії

| Операція | Час, мс |
|---|---|
| $100\,000 \times \text{Add}(x)$, список без заданої місткості | ~1.5 мс |
| $100\,000 \times \text{Add}(x)$, з $\text{new List<int>}(100000)$ | ~0.6 мс |
| $100\,000 \times \text{Insert}(0, x)$ | ~1200.0 мс |
| $1\,000 \times \text{Contains}$ (неіснуюче) у списку з $100\,000$ елементів | ~350.0 мс |

1. `List<T>` побудований на масиві. `Add(x)` додає елемент в кінець за $O(1)$. `Insert(0, x)` зсуває всі $N$ елементів вправо ($O(N)$), що вимагає багатьох копіювань.
2. `new List<int>(100000)` одразу виділяє необхідний блок пам'яті, уникаючи перевиділення пам'яті та копіювання старих елементів.
3. `Contains()` виконує лінійний пошук $O(N)$. Для неіснуючого значення робиться 100 000 порівнянь. $1\,000$ викликів виконують $100\,000\,000$ операцій.

## Крайові випадки

| Вхідні дані | Завдання | Очікувано | Отримано |
|---|---|---|---|
| Порожній список | 1–4 | Порожні списки / `Count = 0` / Перевірка: `true` | Збігається |
| Список з 1 елемента | 1, 2, 4 | Коректне вилучення / розділення | Збігається |
| Жоден елемент не підходить | 1, 2 | Порожній результат для 1; список без змін для 2 | Збігається |
| Усі елементи підходять | 1, 2 | Повний список для 1; порожній список для 2 | Збігається |
| Один зі списків для злиття порожній | 3 | Результат повністю копіює другий список; `true` | Збігається |

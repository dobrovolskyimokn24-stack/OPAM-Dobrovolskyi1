# Лабораторна робота 6 — JPEG-lite
**Дисципліна:** Розробка мультимедійних застосунків

## Опис проекту
Реалізація спрощеного алгоритму стиснення зображень JPEG (JPEG-lite) мовою Python.

## Основні компоненти
- **DCT (Дискретне косинусне перетворення):** Пряме та зворотне перетворення блоків 8x8.
- **Квантування:** Застосування матриць квантування залежно від рівня якості `q`.
- **Кодування та декодування:** Повний цикл стиснення та відновлення зображення.
- **Оцінка якості:** Обчислення метрик PSNR та SSIM, побудова графіків залежності стиснення від якості.
